# Older release notes

Release notes, upgrade guides and deployment guides for versions 0.2 to 5.45
(`RELEASE_*`, `UPGRADE_*`, `FINAL_DEPLOYMENT_GUIDE_*`) were removed on 2026-11-18
to keep the repository small. They describe the Python-era releases and are
replaced by `docs/project/` (status, ledger, migrations, API, tests, runbook).

They remain in git history: on GitHub open **History** for the `docs` folder,
or run `git log --diff-filter=D -- docs/` and `git show <commit>^:docs/<file>`.
